# 🎮 Tic-Tac-Toe Game in C

## 📖 Overview

This is a simple command-line implementation of the classic **Tic-Tac-Toe** game written in C. It allows two players to play against each other by taking turns marking spaces on a 3x3 grid.

The project is designed for beginners to practice core programming concepts such as:

* Arrays (2D arrays)
* Conditional logic
* Loops
* Functions

---

## 🚀 Features

* Two-player mode (Player X and Player O)
* Input validation for moves
* Automatic win detection
* Draw detection when the board is full
* Simple and interactive console interface

---

## 🛠️ Technologies Used

* C Programming Language
* Standard Input/Output (stdio.h)

## ▶️ How to Run

### Step 1: Compile the program

```bash
gcc tic_tac_toe.c -o tic_tac_toe
```

### Step 2: Run the executable

```bash
./tic_tac_toe
```

---

## 🎯 How to Play

1. The game is played on a 3×3 grid.
2. Player 1 uses **X**, and Player 2 uses **O**.
3. Players take turns entering a number (1–9) to place their mark.
4. The first player to align three marks (row, column, or diagonal) wins.
5. If all spaces are filled without a winner, the game ends in a draw.
