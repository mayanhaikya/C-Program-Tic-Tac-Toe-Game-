Tic-Tac-Toe Game in CA clean, interactive, and fully functional 2-player Tic-Tac-Toe console game written in C (C99 Standard). Players can enter custom names, play multiple rounds, and keep track of their scores on an automated scoreboard.🚀 FeaturesCustom Player Names: Personalize the match by entering custom names for Player X and Player O.Scoreboard System: Keeps track of Player X wins, Player O wins, and draws across multiple rounds.Input Validation: Prevents players from picking already-occupied cells or entering coordinates out of the $3 \times 3$ grid boundaries.Robust Error Handling: Clears input buffers to prevent game crashes from accidental invalid character inputs.Multi-round Support: Ask players at the end of each round (and game) if they'd like to continue.🛠️ How to Compile and RunPrerequisitesTo run this project, you need a C compiler (like gcc) installed on your system.Step-by-step Installation1. 🎮 How to PlayRun the program.Enter the names for Player 1 (X) and Player 2 (O).On your turn, enter the row and column numbers separated by a space (e.g., 1 1 for top-left, 2 2 for center).Get 3 of your marks in a row (horizontally, vertically, or diagonally) to win!📁 File StructurePlaintext├── tic_tac_toe.c   # Main source file containing all game logic
